# In Tune: Cycle Journal

A private period and cycle journal for iPhone.

The planned small TestFlight beta is free, requires iOS 27.2 or later, and will use private invitations. Estimates are not medical advice or birth control. It includes built-in Care ideas. Apple Health isn't connected in this beta.
